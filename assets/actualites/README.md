# Illustrations des actualités

`terre.webp` est une mosaïque satellitaire NASA (Blue Marble 2002), créditée dans `credits.json`. Elle illustre les publications sans photo d’article réutilisable ni engin précisément reconnu ; elle ne représente pas un événement. Aucun logo NASA n’est repris.

Les photos d’articles officielles GOV.UK sont chargées depuis le serveur de l’éditeur et créditées dans `actualites.json`. Les illustrations d’engins réutilisent les photos libres de l’atlas, avec leurs auteurs et licences. Les images de presse non autorisées ne sont pas copiées.

`navigation.svg` et `energie.svg` sont des dessins créés pour Radar pour les thèmes sans photo réutilisable. Ils sont signalés comme illustrations, jamais comme photos de l’article.
